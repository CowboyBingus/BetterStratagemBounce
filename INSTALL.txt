Better Stratagem Bounce

Lets stratagem balls stick and activate on more surfaces instead of bouncing away.

Install: With the game closed, import BetterStratagemBounce.zip into HDArsenal or HD2MM, then enable and deploy it.
Use one manager for the installation.
Remove any previous manual installation before switching to a manager.
For an HD2MM "empty options" warning from an earlier ZIP, remove the old library entry and import this ZIP again.
To uninstall, disable the mod, purge deployed files, and redeploy any other enabled mods through the same manager. Then remove its library entry.
