# Better Stratagem Bounce

Better Stratagem Bounce now ships inside the **[Vanilla Plus Megapack](https://github.com/CowboyBingus/VanillaPlusMegapack)**, the
HellForge code mod that holds all twenty-five CowboyBingus Helldivers 2 mods in one download. Each mod is a component
you switch on or off in the pack's settings. Better Stratagem Bounce's C source is in
[`src/components/better_stratagem_bounce`](https://github.com/CowboyBingus/VanillaPlusMegapack/tree/main/src/components/better_stratagem_bounce).

The standalone Lua mod (v15.4.1 and earlier, for the Lua mod loaders) is on the
[`legacy`](https://github.com/CowboyBingus/BetterStratagemBounce/tree/legacy) branch. Its releases and tags are unchanged.
