Better Stratagem Bounce - v15.4

Lets stratagem balls stick and activate on more surfaces instead of bouncing away.

Release for Steam build 25480438 / EXE 1.8.46015.0. Offline checks passed; in
live play the mod loads and applies its stratagem navigation settings. v15.4
ran in two joined live missions.

INSTALL
1. Close Helldivers 2.
2. Import Better-Stratagem-Bounce-v15.4.zip and Bingus-Shared-Loader-v19.zip
   into Arsenal or HD2MM. Replace any older Better Stratagem Bounce or loader
   entry rather than enabling two copies.
3. Enable both packages. With Arsenal's default priority, place Bingus Shared
   Loader last; with first-mod priority, place it first.
4. Purge and Deploy, then start the game normally.

Use one manager. Keep the loader enabled; managers do not install it
automatically. You do not need the other gameplay mods.

To upgrade from an older package: remove its old library entry, purge
deployment, import the current ZIP and Bingus Shared Loader, then redeploy.
Replace all enabled older CowboyBingus packages that bundled the loader. Remove
previous manual files before switching to a manager. Do not enable withdrawn
native reinforcement prototypes.

To uninstall, disable this mod, purge deployment, and redeploy the remaining
mods. Remove Bingus Shared Loader only if no dependent mods remain enabled.

Bingus Shared Loader is the renamed Shared Mod Loader; its manager GUID is
unchanged. Replace the old entry instead of enabling both names. Current
Reinforcement Beacons Fixed is an optional separate module.

Requires Bingus Shared Loader v18 or newer (API 1; v19 is current):
https://github.com/CowboyBingus/BingusSharedLoader/releases/latest
